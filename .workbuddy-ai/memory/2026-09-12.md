## 对标调研：正经研究院网站还缺什么（未实施，仅分析）

对标的四家：**NBER**（Working Paper 立命 + In the News + Videos + 每周邮件订阅）、
**Brookings**（topic/region 中心 + experts + podcasts + 大量 media）、
**清华国情研究院**（国情报告系列 + 重要期刊论文带「点击下载/阅读全文」+ 国情讲坛 + 全站双语）、
**北大国发院**（10 个一级栏目：概况/师资/教学/研究/智库/公益/校友/捐赠 + 主办《经济学》季刊 + 讨论稿 + 博士后流动站 + `en.nsd.pku.edu.cn`）。

**核心结论**：51 页骨架已齐，缺的不是页面数量，是三样 —— **可获取的全文、可验证的人、可被第三方引用的影响力证据**。

### 一层：自相矛盾（说了却没兑现，最伤可信度）
1. **学术委员会 0 位委员** —— `/about` 写了职责（审议/立项/评价），`/notices` 里还有「经学术委员会确认」
   「邀请学术委员会成员参与评审」，但全站找不到一个人名。**比「没有这个栏目」更糟，是自相矛盾。**
2. **成果全文 0 篇** —— `publications` schema 有 `pdf` 字段、`[slug].astro:121` 会渲染 PDF 按钮，
   但 10 篇内容 **0 篇填了**，`dist` 里按钮出现 0 次。管道铺好没接通。
3. **无工作论文系列** —— 只有已发表成果，看不见在研管道。NBER 靠 WP 立命、国发院有「讨论稿」。

### 二层：标配缺失
4. ORCID **0/4**（字段+渲染都有，没填）；Scholar 1/4 且是 `https://scholar.google.com/` 占位符。
5. **无英文版** —— `nameEn` 4 条齐全、国发院/国情院都双语，只差一层路由。
6. **无媒体提及 / In the News** —— 影响力只有自述，无第三方背书。
7. **无 Newsletter 订阅** —— 只有 RSS（仅技术受众）。

### 三层：锦上添花
- 给人看的 HTML 网站地图（现只有给爬虫的 sitemap.xml）
- 视频/讲座录像
- 成果**按作者筛选**（现有类型/年份/标签三档，独缺作者）+ 批量导出 BibTeX
- `/datasets` 仍硬编码 3 条，且 `access: 需提交研究用途说明后获取` 却无申请通道

### 已做得比多数同类站好的
零 JS 静态输出、构建期门禁（3533 条内部链接逐条校验）、BibTeX 引用、专题聚合、JSON-LD 七种类型。

**方法论（可复用）**：查「半建成的字段」用这个思路 —— schema 里声明了、模板里渲染了、
但**内容一条都没填**的字段，是比「完全没有这个功能」更隐蔽的缺陷，因为代码审计不会报错。
扫法：对每个集合统计 frontmatter 各字段的填充率，填充率为 0 的即为「空管道」。

## 封面图落地上线：把用户上传的图真正用到首页

**做了什么**：应「上传的图片也支持渲染」，把用户 23:54 上传的 `public/images/image-1789142094159-vkt8.png`
设为头条新闻 `2026-award` 的封面（走 admin API，非手改文件，顺带复验持久化）。

```bash
PUT /api/content/news/2026-award   # 注意路由是 /api/content/:collection/:id，不是 /api/entries/:collection/:id
{"data": {..., "cover": "/images/xxx.png", "coverAlt": "年度管理科学优秀成果奖颁奖现场"}, "body": "..."}
```

**复验链**：build 51 页 → audit ✅ → smoke 30/30。
`dist/index.html` 真实 `<img src="/images/...">` = 1，抽象 SVG 占位 = 30（其余条目正确回退）；
该图出现在**轮播图第 1 张**（`data-active="true"`、`loading="eager"`），详情页也有；
`curl -I` 返回 200 / 1069681 B。

**注意**：dist 体积因此从约 0.85 MB 涨到 **1.89 MB**，首页首屏要 eager 加载 1.07 MB 的 PNG。
已向用户提出压缩到 200–300 KB（约 1600px 宽 JPEG/WebP）。本机隔离 Python **无 Pillow**，需先装才能处理。

**踩坑记录**：
- 工作区被父仓库 `.gitignore:77`（`数字管理研究院网站/`）整个忽略，
  `git status` / `git diff` 恒为空，**不能用来验证改动**——直接 Read 文件或比对字节。
- Windows 上 curl 提交中文仍会发 GBK（09-11 已查明），所以 PUT 的 JSON 一律由 Python
  `json.dump(..., ensure_ascii=False)` 写盘再 `--data-binary @file`，杜绝乱码。
- `curl -o /dev/null` 在本机偶发 exit 23（写 body 失败），改用 `-I` 看状态码更稳。
