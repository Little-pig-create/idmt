## 发现的真实 Bug：开发注释被发给了所有访客

**`.astro` 模板里的 `<!-- -->` 会被原样输出到 HTML**（不像 JSX 自动剥注释）。
用 `{/* */}` 写才会被剥掉。

**实测规模**：只有 4 个源文件（`BaseLayout` / `Header` / `Footer` / `index`）含 `<!--`，
共 21 处，但因为这 4 个在每页都渲染 → **51 个页面共 472 处 / 16.5 KB**。
最长的注释 159 字符，把设计决策和「不要这样做」的内部备注一起发给了访客。
`taste.mjs` 会先剥注释再做文本分析，所以**永远不会发现这件事**。

**修法**：21 处 `<!-- -->` → `{/* */}`（转换前先检查注释里有无花括号，有就会破坏表达式）。
结果：472 处 → 11 处（剩下的是 Astro 自身的空注释 `<!-- -->` 与 `<!--astro:end-->`，约 110 字节）。

**固化为门禁 `HYG-001`**（加在 `audit.mjs` 里，不是 taste）：
产物 HTML 不得出现**有内容**的注释；Astro 自身的空注释与 `astro:` 前缀标记排除在外。
**反向测试**：往 `dist/index.html` 注入 `<!-- 注入的泄漏注释 -->` → 退出 1 并精确报出 → 还原复验通过。
（这个规则可以直接注入 dist 测试，不用重新构建 —— audit 本来就是扫 dist。）
