## 首页区块顺序

1. **首屏**：全屏城市低空场景图 + 深色遮罩；眉标签、两行主张、一段说明、两个 CTA；
   右侧「CORE CAPABILITIES」玻璃面板（≥1280px 显示）；底部 4 项统计。
2. **机构定位**：左侧主张 + 说明 + 三个标签；右侧 2×2 原则卡（面向未来 / 交叉融合 / 科教结合 / 开放创新）。
3. **研究方向**：9 张卡片，首张跨 2 列 2 行（大图 + 关键能力 + 关键词）。
4. **技术体系**（暗面）：三个 Tab（算力底座 / 智能系统 / 产业场景），左图右文。
5. **产品与方案**（暗面）：Embla 轮播，卡片含分类、概述、首个指标。
6. **技术平台**：左侧粘性说明 + 右侧 10 间实验室网格。
7. **治理与发展**：三阶段卡片（规划目标，注明非业绩）。
8. **研究进展**：头条实测记录 + 研究记录（4282 km / 8→4 道工序 / 102×102mm BGA）+ 重点方向。
9. **合作**：合作方 Marquee。
10. **CTA**：加入我们。

## 状态与空值

- 集合为空：区块不渲染（首页各段均有条件）。
- 新闻无封面：回落 `/images/lab-line.webp`。
- 产品无指标：轮播卡片不显示指标行。
- 搜索无结果：显示「没有找到与「query」相关的内容」。

## 响应式

| 断点 | 行为 |
|---|---|
| < 640 | 单列；首屏字体 2.6rem；统计 2×2；导航收进 Sheet |
| 640–1023 | 两列卡片；产品轮播 52% 宽 |
| 1024–1279 | 三列；首屏右面板隐藏 |
| ≥ 1280 | 首屏右面板显示；容器 1440 |

## 无障碍

- 每页唯一 `h1`；跳转链接；`:focus-visible` 2px 品牌色描边。
- 图片必须有 `alt`（装饰图用空串）。
- 表单控件均有显式 `label`。
- 暗面文字对比度由令牌保证；动效尊重 `prefers-reduced-motion`。
