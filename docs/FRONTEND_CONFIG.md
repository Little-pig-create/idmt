# 前端粒度管理

> 后台（`admin/`）编辑并持久化配置 → **运行时动态构建**下发 → 前台（`src/`）运行时拉取并应用。
> 前后端分离：各自独立构建、独立部署，互不依赖对方的构建产物。

---

## 1. 「动态构建」在本项目的确切含义

需求方指定的「动态构建」，在本仓库落地为 **runtime config resolution（运行时配置解析）**：

| 环节 | 实现 |
|---|---|
| **后台动态构建** | `GET /api/frontend-config` —— 服务端**每次请求时**从落盘配置实时拼装出规范化配置文档 + 内容指纹（revision/ETag） |
| **前台运行时消费** | 页面加载后 `fetch` 该接口，在浏览器里应用到 DOM |
| **配置不预编译** | 配置**不参与** `astro build`。若把配置写进前台源码或构建期注入，就违背了本方案 |

**明确不是**：不是 Astro 构建期注入，不是 SSR，不是多版本产物。

### 与既有 ADR 的冲突（已记录，非静默推翻）

`docs/PORTAL_FRAMEWORK.md` §5.2 / §5.3 明确规定站点坚持「**零 JS 静态输出**」，
并把「依赖 JS 运行时」列为**净损失**；§281 的复查触发条件是
「若出现登录态 / 个性化 / 服务端实时数据，重新评估是否需要 SSR」。

本功能属于「运行时应用配置」，触发该复查条件。**本次选择静态壳 + 运行时应用**，代价：

1. **被禁用的页面无法在服务端拦截** —— 静态 HTML 已构建，客户端只能读到配置后替换为提示页。
   内容仍在 HTML 源码里，懂技术的人可查看。要做到真正隔离必须上 SSR。
2. **可能有一闪** —— 默认内容先渲染，配置到达后替换（本实现用默认不解藏 + 超时兜底压到最低）。
3. **站点不再零 JS** —— 新增约 4.4 KB（gzip）配置运行时；`audit` 预算 JS ≤ 30 KB，当前 13.1 KB，仍充裕。

若要消除第 1 条，需引入 SSR adapter —— 那是独立改造，不在本模块范围。

## 2. 前后端分离边界

```
shared/frontend-config-contract.mjs     ← 契约（纯 JS，前后台共用同一份，避免漂移）
        ├── admin/frontend-config-store.mjs   ← 后台：持久化 + 校验 + 动态构建
        ├── admin/server.mjs                  ← 后台：HTTP 接口
        └── src/lib/frontend-config.ts        ← 前台：运行时读取 + 默认回落
```

| 职责 | 归属 | 约束 |
|---|---|---|
| 配置编辑界面 | `admin/src/components/FrontendConfig.tsx` | 只编辑，不渲染前台 |
| 持久化与校验 | `admin/frontend-config-store.mjs` | **不含任何前台默认值** |
| 动态构建下发 | 同上 + `server.mjs` | 每次请求实时拼装 |
| 运行时应用 | `src/scripts/frontend-config-runtime.ts` | 只拉取与应用 |
| 默认值 | `src/lib/frontend-config.ts` | **全部属于前台**，后台不得内联 |

**前台产物里不含后台代码**：运行时只 import 共享契约与前台 lib，不 import `admin/**`。

## 3. 接口（全部为**新增**，未改动任何既有接口）

| 方法 | 路径 | 用途 | 说明 |
|---|---|---|---|
| `GET` | `/api/frontend-config` | **前台消费入口** | 动态构建下发；带 `ETag`，命中返回 304 |
| `GET` | `/api/frontend-config/source` | 后台编辑回填 | 返回落盘配置 + 规范化警告 |
| `PUT` | `/api/frontend-config` | 保存 | 非法值被剔除并返回 warnings；**需要管理权限** |
| `GET` | `/api/frontend-config/surface` | 可配置面清单 | 路由 / 区块 / 元素 / 语言 / 令牌 / 开关白名单 |

`GET /api/schema` 仅**追加** `capabilities` 字段，既有 `collections` 结构未变。
`/api/content/*`、`/api/stats`、`/api/build`、`/api/assets` 均未改动。

**配置文档形状**（`version` / `updatedAt` 由后台维护）：

```jsonc
{
  "routes":   { "/join": { "state": "hidden|disabled|enabled", "access": "public|restricted", "disabledMessage": "…" } },
  "blocks":   { "/": { "order": ["research","news"], "items": { "statBand": { "enabled": false }, "research": { "title": "…" } } } },
  "elements": { "*": { "adminEntry": { "enabled": false } }, "/": { "joinPrimary": { "label": "…", "href": "…", "icon": "…" } } },
  "i18n":     { "zh-CN": { "nav.about": "…" }, "en": { "…": "…" } },
  "theme":    { "tokens": { "--color-accent": "#0b5cad" }, "logoText": "…", "footerNote": "…" },
  "features": { "carouselAutoplay": false }
}
```

## 4. 粒度与独立生效

| 粒度 | 键 | 独立生效方式 |
|---|---|---|
| 页面/路由 | `routes[path]` | 三态（启用/隐藏/禁用）+ 访问级别；**隐藏 = 不展示但可直达**，禁用 = 不可访问并给出提示 |
| 区块/组件 | `blocks[route].items[id]` / `.order` | 开关与文案逐键覆盖；`order` 只重排**列出的**区块，未列出的保持原相对顺序 |
| 元素 | `elements[scope][id]` | 全局 `*` 与页面级两套作用域，页面级优先；每个元素独立开关/文案/跳转 |
| 文案 i18n | `i18n[lang][key]` | 按语言分表存储，改一种语言**不触碰**其他语言 |
| 主题样式 | `theme.*` | 令牌只允许白名单内 + `#hex`，防止注入任意 CSS |
| 功能开关 | `features[key]` | 白名单键；未配置取前台默认 |

**逐键回落**：所有读取函数对每个键单独判断，缺字段即用默认 —— 这是「互不牵连」的实现保证。

## 5. 异常与边界（全部实测通过）

| 场景 | 行为 |
|---|---|
| 无配置数据 | 后台显示「暂无配置，使用前端默认内容」；前台**与改动前逐字节一致**（见 §7） |
| 配置项缺字段 | 该键取默认，其余键照常生效 |
| 配置值非法 | 后台保存时剔除并在界面列出可读警告；前台另有一层运行时校验，非法即当未配置 |
| 配置文件 JSON 损坏 | 后台仍可打开（返回空配置 + 警告），前台按未配置渲染 |
| 接口失败 / 网络不通 | 前台静默回落默认，**不阻塞、不白屏**（3s 超时） |
| 被禁用页面 | 给出明确不可用提示（保留页头页脚，有「返回首页 / 全站搜索」退路） |
| 被隐藏页面 | 导航不显示，直接输入地址可正常访问 |
| 无权限账号 | 侧栏该项禁用并标注角色；写接口返回 403 + 可读错误 |
| 保存失败 | **不清空已填内容**，报错提示保留在表单上 |

> ⚠️ **权限不是安全边界**。后台只监听 `127.0.0.1`，无账号/登录/会话。
> `ADMIN_ROLE` 环境变量仅用于满足「无权限账号看不到该模块」的界面要求。
> 真正的边界是回环监听。要真鉴权需独立改造。

## 6. 配置文件

`src/data/site-config.json` —— 由后台写入，随源码提交，可 diff。

- 后台保存时**先规范化再落盘**，因此文件里永不含非法值
- 「保存成功」等价于「前台一定能解析」
- 删掉该文件即回到全默认，服务端会按「未持久化」处理

## 8. 开发期验证脚本（未纳入门禁）

| 脚本 | 作用 |
|---|---|
| `scripts/_e2e_config.py` | 前台运行时应用 18 项断言（配置应用、导航、隐藏vs禁用、接口失败回落） |
| `scripts/_e2e_config2.py` | i18n 语言隔离、损坏配置、空配置无副作用（9 项） |
| `scripts/_e2e_admin.py` | 后台界面 19 项断言（模块可见、六页签、空状态、保存反馈、无权限禁用） |
| `scripts/_regression_guard.py` | 空配置下的产物回归守卫 |

需要：后台 `node admin/server.mjs`（4322）+ 站点 `npm run preview`（4321）。
两个 e2e 脚本自带「静态产物 + `/api` 反代」的本地服务，因为站点是静态站、
后台 API 在另一端口，浏览器需要同源才能验证真实行为。
